An 8B model that checks its own work on JEE Advanced 2026

Qwen3-VL-8B is never fine-tuned. Around it we put a Python sandbox for the arithmetic, a second model that names the first wrong step, a trained verifier that picks the final answer, and a library of solved past problems. The 2026 papers came out after the model, and we froze the system before running it on them.

What the critic and corrector do

InternVL3.5-8B checks each of the 1,632 solutions on 2026 (204 questions × 8) and names the first wrong step. Qwen3-VL-8B then redoes the solution from that step.

05 · Method

Four modules around one frozen model, on one 12 GB GPU

The solver is Qwen3-VL-8B in 4-bit AWQ, served with vLLM. Only the verifier is trained, and it trains on a CPU.

  1. A

    Code sandbox

    The model writes Python for the calculations. We run each block, paste its output back into the solution, and the model carries on from there.

    Checks
    AST whitelist, no exec/eval/open
    Process
    python -I, empty temp dir
    Limits
    10 s · 1 GB · 1 MB output
    Fallback
    plain CoT if no answer
  2. B

    Critic and corrector

    A different model, InternVL3.5-8B, names the first wrong step. The solver keeps everything before that step and redoes the rest.

    Critic
    InternVL3.5-8B
    Rounds
    up to 3
    Cut-off verdict
    forced, unparsed 76 → 1 of 501
    Gate
    δ = −0.08
  3. C

    Learned verifier

    Scores each of the 16 answers and picks the best one. The training labels cost nothing: the paper's scorer already marks every past answer right or wrong.

    Model
    XGBoost pairwise ranker
    Features
    agreement, code ran, cut-off, critic flags…
    Data
    12,096 answers, 2019–2024
    Chosen by
    leave-one-year-out
  4. D

    Retrieval

    The model tags the question as "subject | topic | method". Solved problems with a close enough tag go into the prompt as worked examples.

    Embedder
    bge-small + FAISS
    Knowledge base
    606 solved problems
    Similarity
    0.9 tag + 0.1 text
    Threshold
    τ = 0.882
Keeping the test clean

How we know 58.8% is honest

  1. Frozen first. The final system was fixed and written down before any 2026 run.
  2. Year split. Training, tuning and the knowledge base use 2019–2024 only.
  3. Twins kept apart. A question's English/Hindi twin never appears in its training or retrieval.
  4. De-duplicated knowledge base. Entries with cosine ≥ 0.90 to any test question were removed.
  5. Fair baseline. Majority voting gets the same token budget as our system.
  6. Hindi 2026 built by us. 102 Hindi crops from the official papers, each matched to its English twin.
  7. Pre-registered steps. Later ideas had their pass rule committed before running, and every outcome is reported.
  8. Paper's own scorer. Answers are marked with the base paper's extraction and scoring code.
